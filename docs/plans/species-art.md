# Painted species art

This page proposes using paintings of the common species as the default
species pictures on the website and the [e-paper display](eink-display.md).
Nothing on this page is built, and no paintings exist yet.

## How it works

1. Each painting is scanned or photographed and saved in a folder, with the
   species' scientific name as the filename, for example
   `art/species/Junco_hyemalis.jpg`.
2. A script makes the sizes that the website needs, and a version dithered
   to the e-paper panel's six inks.
3. The website shows a painting wherever one exists: species hover cards, the
   Species page, the Display slideshow, and Live labels. It shows the current
   photo for species without a painting, so paintings can be added one at a
   time.

## Painting for six colors

The e-paper panel mixes six inks with dot patterns to show other colors.
Paintings reproduce best when they have the following qualities:

- A bold shape on a white or plain background, so the bird reads from across
  a room.
- Saturated colors close to the panel's inks: red, yellow, blue, and green.
  Soft washes and browns become dot patterns.
- High contrast, so the bird's outline stays crisp.

To check a style before you paint more, preview a scan dithered to the six
inks.

## Which species first

To choose which species to paint first, sort the Overview page's species by
minutes heard. The most-heard species appear on the display most often.
